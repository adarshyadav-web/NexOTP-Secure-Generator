# NexOTP Secure Generator

A sleek and efficient One-Time Password (OTP) generator featuring interactive digit animations and a modern glassmorphic interface.

## 🚀 Features

- **Instant Generation**: One-click secure 4-digit code.
- **Interactive Animations**: Smooth digit pop effects.
- **Glassmorphic UI**: Clean, high-end design.
- **Mobile Optimized**: Perfect for quick access on any device.

## 🛠️ Technologies Used

- **HTML5**, **CSS3**, **JavaScript**
